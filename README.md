# 🧠 Deep Learning Fundamentals & Neural Network Implementation

## 📌 Project Title

**Breast Cancer Classification Using Artificial Neural Network (ANN)**

---

## 📖 Project Overview

This project focuses on understanding and implementing the fundamentals of **Deep Learning** using an **Artificial Neural Network (ANN)**.

The **Breast Cancer Wisconsin dataset** is used for binary classification. The ANN is implemented using **TensorFlow/Keras** and is trained to classify the data into two target classes.

The project also compares the performance of the ANN with a traditional Machine Learning model, **Logistic Regression**.

---

## 🎯 Objectives

The main objectives of this project are:

- Understand the fundamentals of Deep Learning.
- Understand the structure of an Artificial Neural Network.
- Understand input, hidden, and output layers.
- Understand activation functions.
- Implement an ANN using TensorFlow/Keras.
- Train and evaluate a neural network.
- Understand accuracy and loss.
- Visualize training and validation performance.
- Generate a confusion matrix and classification report.
- Compare ANN performance with a traditional Machine Learning model.

---

## 📊 Dataset

The project uses the **Breast Cancer Wisconsin dataset** available through Scikit-learn.

### Dataset Details

| Property | Value |
|---|---:|
| Total Samples | 569 |
| Total Features | 30 |
| Problem Type | Binary Classification |

The dataset contains numerical features used to classify the samples into two target classes.
